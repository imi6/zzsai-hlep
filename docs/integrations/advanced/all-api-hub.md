# All API Hub

All API Hub 是一个开源浏览器扩展，能集中查看吱吱鼠AI 的余额、Key 和模型，还能把配置导出到 Cherry Studio、CC Switch 等客户端。它是配置管理工具，不能拿来聊天。

## 1. 安装扩展

优先从官方渠道安装，这样能自动更新：

- [Chrome Web Store](https://chromewebstore.google.com/detail/all-api-hub-%E2%80%93-ai-%E4%B8%AD%E8%BD%AC%E7%AB%99-new/lapnciffpekdengooeolaienkeoilfeo)
- [GitHub 发布页](https://github.com/qixing-jk/all-api-hub)
- [官方文档](https://all-api-hub.qixing1217.top/)

从 GitHub 下载的手动版需要在扩展管理页开启开发者模式，再「加载已解压的扩展」，这种方式不会自动更新。

## 2. 登录吱吱鼠AI

1. 在装了扩展的 **同一个浏览器配置文件** 里打开 [https://zzshu.cc](https://zzshu.cc)。
2. 登录控制台，保持登录状态。
3. 点浏览器工具栏里的 All API Hub 图标。

自动识别会读取当前的登录会话。不要把 Cookie、访问令牌或完整 API Key 放进截图或分享出去的配置里。

## 3. 添加账号

1. 点击「添加账号」。
2. 站点地址填 `https://zzshu.cc`。
3. 点击「自动识别」。
4. 核对识别出的站点名称、用户名和用户 ID 是不是你自己的账号。
5. 点击「保存账号」。

## 4. 自动识别失败时手动添加

1. 确认是在装扩展的同一个浏览器配置文件里登录的吱吱鼠AI。
2. 如果开了会拦截 Cookie 的隐私限制，临时关掉后重试。
3. 还是失败就选「手动输入」，填用户 ID 和账号访问令牌。
4. 保存前再核对一遍站点地址。

::: warning 两种令牌别搞混
- **账号访问令牌**：用来读取账号资料和余额，All API Hub 手动添加账号时用。
- **模型 API Key**（`sk-` 开头）：用来调用模型，在 [令牌页面](https://zzshu.cc/console/token) 创建。

两者不能互相替代。
:::

## 5. 管理 API Key

1. 打开「密钥管理」，选刚添加的吱吱鼠AI 账号，刷新列表。
2. 可以查看、创建、编辑、删除或复制 Key。
3. 需要反复导出的 Key，可以存进「API 凭据库」。

创建 Key 时注意选对分组，分组决定这个 Key 能用哪些模型。分组名和模型的对应关系见 [模型广场](https://zzshu.cc/pricing)。

## 6. 查看模型和价格

1. 打开「模型价格」。
2. 数据源选吱吱鼠AI 账号或某个 API 凭据。
3. 刷新后搜索模型 ID，核对模型是否可见、支持的协议和倍率。

模型看不到，说明当前 Key 的分组里没有它，换一个分组的 Key。不要在导出时手写当前凭据看不到的模型。

## 7. 导出到其他客户端

1. 回到「密钥管理」，找到要用的 Key。
2. 点击「导出」，选择目标客户端，例如 Cherry Studio、CC Switch。
3. 在导出预览里核对：

| 项目 | 应该是 |
| --- | --- |
| 站点地址 | `https://zzshu.cc` |
| OpenAI 兼容 Base URL | `https://zzshu.cc/v1` |
| Key | 掩码显示的 `sk-…` |
| 模型 | 准确的模型 ID，例如 `claude-sonnet-4-6` |

4. 确认后写入目标客户端。

## 8. 验证

在目标客户端里选模型发一条短消息，然后打开 [使用日志](https://zzshu.cc/console/log)，核对请求时间、模型和状态。

「导出成功」只表示配置写进去了，不代表模型调用能成功。以客户端收到回复、日志里有记录为准。

## 本地数据与备份

- 扩展数据默认只存在当前浏览器本地。
- 导出的 JSON 备份里可能有账号令牌和 API Key，按敏感文件保管。
- 只有你主动配置了 WebDAV，数据才会同步到指定的存储。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 自动识别失败 | 确认登录发生在同一个浏览器配置文件里，必要时改用手动添加 |
| 能看到余额但没有 Key | 先在 [令牌页面](https://zzshu.cc/console/token) 创建一个 Key，再刷新 |
| 导出后地址不对 | 站点识别用根地址；OpenAI 兼容客户端一般要带 `/v1` 的地址 |
| 模型列表里缺目标模型 | Key 所在分组不包含这个模型，换分组 |

## 恢复

在扩展里删除吱吱鼠AI 账号即可清除本地保存的令牌和 Key。已经导出到其他客户端的配置，需要到对应客户端里单独删除。不再使用的 Key 可以在令牌页面停用。
